What is CaddyBar?

CaddyBar lives in your menu bar and lets you create local domains with automatic SSL certificates (HTTPS) effortlessly. No more manually editing Caddyfiles or managing complex reverse proxy configurations.

Key Features

Menu Bar Integration

Clean, unobtrusive interface that stays out of your way with real-time status indicators showing Caddy's running state.

Site Management

Visual interface for creating and managing reverse proxy sites with support for custom domains and subdomains.

Automatic HTTPS

Built-in TLS/SSL support powered by Caddy's automatic certificate management with zero-configuration certificates.

Flexible Configuration

Run in standard mode (ports 8080/8443) or privileged mode (ports 80/443) with custom HTTP headers support.

Advanced Features

Optional privileged helper for ports 80/443, live logging to monitor Caddy logs, and auto-updates via Sparkle.
